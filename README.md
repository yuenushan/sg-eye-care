# SG 护眼

环境光场景化护眼遮罩 Chrome 扩展(Manifest V3)。通过在页面上叠加暖色与暗色两层遮罩降低屏幕亮度和蓝光刺激,提供三档环境光预设:

- 明亮办公室(色温 22 / 调光 3)
- 室内灯光(色温 47 / 调光 10)
- 关灯房间(色温 67 / 调光 22)

也可拖动滑块自定义色温与调光值。设置通过 `chrome.storage.sync` 云同步,所有打开的标签页实时生效。

## 功能

- 每站开关:可对指定域名单独禁用遮罩
- 遮罩使用 `mix-blend-mode: multiply` 固定层实现,`pointer-events: none`,不拦截页面交互
- 内容脚本在 `document_start` 注入,页面加载即生效
- 支持 `/` 步进按钮长按连续调节

## 安装(开发者模式)

1. 下载本仓库或克隆到本地
2. 打开 `chrome://extensions/`,开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」,选择本目录

## 文件结构

```
manifest.json   # MV3 配置,权限仅 storage / tabs
content.js      # 内容脚本:渲染暖色层与暗色层,监听 storage 变更
popup.html      # 弹窗 UI
popup.js        # 弹窗逻辑:预设切换、滑块调节、每站开关
icons/          # 16 / 48 / 128 图标
```

## 权限说明

- `storage`:保存开关、预设、自定义参数、禁用站点列表
- `tabs`:弹窗中读取当前标签页 URL 的域名,用于每站开关
